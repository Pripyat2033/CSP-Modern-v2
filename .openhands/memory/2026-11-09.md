## Fabric 1.20.1 gotcha that cost time
`ResourceManager.findResources(prefix, predicate)` — the `prefix` argument is a
DIRECTORY-style match. `findResources("opb82_rules", p -> p.getPath().endsWith(".json"))`
returns NOTHING for a file at `data/csp/opb82_rules.json`. Use the empty prefix and match
the exact path instead: `findResources("", id -> id.getPath().equals("opb82_rules.json"))`.
Symptom was "Loaded 0 articles" with no error. Instrument with a debug dump of
`findResources("", p->p.getPath().endsWith(".json")).keySet()` to see the real namespace/paths.

## Domain facts from Ben (2026-11-09) — authoritative, treat as spec
- **MTK display** = a large CIRCULAR mimic board (мнемосхема) of the RBMK core, made of
  tiny lamp covers. One lamp per channel: ~1663 fuel channels + 211 boron control rods
  (Ben's figures; exact count must be locked down before building). Each lamp cover is
  small, shows a coordinate number like "45.53" (45=horizontal, 53=vertical) that maps to
  an invisible 3D model of the core. Colour = state (white=fuel, green=rod, etc.; the real
  Unit-4 palette is unknown).
- **Workflow**: operator requests a "SKALA code" (e.g. K0T5000) on the SKALA Request Device
  -> SKALA returns data -> operator flips the "sub-programme 4" switch on the MTK -> the
  matching channels light up. Codes are real and number in the thousands.
- **Current MTK block is far too big** to be the wall board. Needs to be a wall panel
  (multi-block / large BE) sized in bits, with ~1874 addressable lamp sub-cells.
- **ICMS** = Ben's own acronym, "Industrial Control and Monitoring System". He is NOT sure
  it is historically accurate. ICMS trio = Control Panel + Message Input + Message Output
  (reads as a plant-wide messaging/telemetry network). Industrial Control Block = local
  machine controller. (Real Soviet term for process control = АСУ ТП.)
- **Scale**: 1 MC block = 1 m^3. The plant was designed on a 6 m structural grid; 1 m blocks
  cannot represent the detail -> hence the bit system. Ben wants to ABANDON normal MC blocks
  entirely and go full custom bit system.
- **Blueprints**: Ben has ChNPP blueprints on his own machine. The "Gosstroy engine" exists
  to generate period-accurate Soviet structures where no blueprint survives.
- **Goal**: build the WHOLE plant, then run the 1986 experiment. The RBMK + radiation
  systems must be 1:1 perfect, "no exceptions", because dumbing them down would ruin the
  experiment.
- **Player** = Director of ChSZO (Chernobyl Special Zone of Operation: plant + Pripyat +
  Duga-1 radar + area villages/towns). Top of the chain of command.
- **SHERDLU**: Ben recalls a past worker voice-synthesis/talking system by this name.
  **It does NOT exist in this repo** (searched: no speech/voice/tts/dialog code at all).
- Ben has NOT tested talking to workers; workers currently have no interaction at all.
