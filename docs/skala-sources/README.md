`yt-dlp --write-auto-sub`. These are the primary source for `docs/SKALA-MODEL.md`.

| 96GMpnLVPuo.txt | FS-1501 punch-tape reader restoration |
| 6CFUYtLKBfI.txt | ES-5061 disk drive / TI-D probe |

Note: auto-transcripts contain recognition errors (e.g. "DRAG" for DREG, "SCADA"
for SKALA, "Kerva"/"Katerva"). The `docs/SKALA-MODEL.md` document corrects these
against context. The `.vtt` files are kept alongside the plain text.
